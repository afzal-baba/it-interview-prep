## Background & Atmosphere

### Animated Network Background
- Canvas-based animated node network with ~90 nodes (responsive count)
- Nodes drift slowly around the viewport
- Connections draw between nearby nodes (140px range) with low opacity (0.15)
- Node color: rgba(180,200,255,0.5)
- Connection color: rgba(140,170,255,0.15)

### Particle Flow System
- ~40 floating particles that drift upward
- Colors: cyan (#5be3d8) and violet (#8f7bf0), alternating
- Particles spawn from bottom, fade as life increases
- Light opacity (0.5) with blur effect
- Regenerates particles as old ones fade

### Glow Orbs (Static)
- Positioned absolutely, fixed, blurred heavily (110px blur)
- **Glow 1:** Violet glow, top-left (-220px top, -160px left), 640x640px
  - `radial-gradient(circle, rgba(95,120,240,0.35), transparent 70%)`
- **Glow 2:** Cyan glow, top-right (-100px top, -200px right), 560x560px
  - `radial-gradient(circle, rgba(91,227,216,0.22), transparent 70%)`
- **Glow 3:** Rose glow, bottom-left (bottom -260px, left 30%), 700x500px
  - `radial-gradient(circle, rgba(240,116,138,0.14), transparent 70%)`

### Vignette Overlay
- Elliptical radial gradient
- Transparent at center, fades to dark at edges
- `radial-gradient(ellipse 1400px 900px at 50% 20%, transparent 40%, rgba(5,7,12,0.75) 100%)`

### Film Grain Texture
- Subtle SVG noise overlay
- Opacity: 0.02
- Mix-blend-mode: overlay
- Creates subtle analog feel without distraction

### Cursor-Tracking Glow
- Fixed 240x240px radial gradient circle
- Follows mouse position smoothly (lerp factor 0.1)
- Violet tint: radial-gradient(circle, rgba(95,120,240,0.25), transparent 70%)
- Blur: 60px
- Opacity fades in/out when mouse enters/leaves viewport

## JavaScript Functionality

### Network Background Animation
- Canvas element: `<canvas id="net"></canvas>`
- Node count: ~90 base, scales down on smaller screens
- Each node has: x, y, vx (velocity x), vy (velocity y), radius
- Nodes bounce off viewport edges
- Connections drawn when nodes within 140px
- Runs on requestAnimationFrame loop
- Respects prefers-reduced-motion setting

### Particle Flow System
- Canvas element: `<canvas id="particles"></canvas>`
- ~40 particles at any time
- Particles: x, y, vx, vy, life, maxLife, size, hue (180 or 260)
- Spawn at bottom, drift upward with slight gravity upward
- Life/maxLife determines opacity gradient
- Regenerate when old particles fade
- Runs on requestAnimationFrame loop
- Respects prefers-reduced-motion setting

### Cursor-Tracking Glow
- Element: `<div id="cursor-glow"></div>`
- Listeners: mousemove, mouseleave
- On move: update targetX/targetY, show glow
- On leave: hide glow
- Smooth lerp: mouseX += (targetX - mouseX) * 0.1
- Updates on requestAnimationFrame
- Position follows cursor with slight lag for premium feel

### Scroll Parallax
- Listen to scroll events with passive: true
- Classes: `.parallax-1` elements
- Update CSS custom property `--offset` based on scrollY * 0.3
- Creates depth effect as user scrolls

## Accessibility & Motion

- **Prefers Reduced Motion:** All animations disabled
  - `@media (prefers-reduced-motion: reduce)`
  - Animation-duration: 0.01ms
  - Transition-duration: 0.01ms
- **Focus States:** Navigation links and interactive elements have clear focus
- **Contrast:** Text meets WCAG AA standards

## Implementation Tips for Replit

1. **HTML Structure:** Create semantic HTML with proper nesting
2. **CSS:** Use CSS custom properties for colors, makes tweaking easy
3. **Canvas Setup:** Initialize canvas sizing on load and resize
4. **Animation Loop:** Use single RAF (requestAnimationFrame) for each canvas
5. **Performance:** Monitor FPS, consider reducing particle/node count on low-end devices
6. **Testing:** Test on mobile viewport, check reduced-motion preference
7. **Fonts:** Use Google Fonts CDN (already imported in head)

## Design Philosophy

This design prioritizes **premium feel through restraint**:
- Dark background shows contrast without overwhelming
- Animations are purposeful, not gratuitous
- Motion blur and glow create depth without distraction
- Color is used selectively (mostly for interaction)
- Typography hierarchy is clear and intentional
- Every animation has a reason (cinematic entrance, interactive feedback, ambient motion)

The result is a landing page that feels **alive, sophisticated, and expensive** without being gaudy.
