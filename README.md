# IT Interview Prep

## Overview
**IT Interview Prep** is a web-based application that acts as a virtual interviewer. It simulates real interview sessions by asking technical, behavioral, and general knowledge questions. The goal is to help users practice, build confidence, and prepare effectively for job interviews in a realistic environment.

## Features
- 🎤 **Interactive Interview Simulation** – Sequential questions that mimic real interview flow.
- 📚 **Multiple Question Types** – Technical, behavioral, and general knowledge.
- 📝 **Response Recording** – Capture and review your answers.
- ⏱️ **Customizable Sessions** – Choose categories, difficulty levels, or timed practice.
- 📊 **Feedback System** – Evaluate performance and track progress.
- 🔧 **Extensible Design** – Easily add new question banks or scoring mechanisms.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript (React or Vanilla JS)
- **Backend:** Node.js / Express (or any server framework you choose)
- **Database:** MongoDB / Firebase / JSON-based storage
- **Deployment:** GitHub Pages, Vercel, or Netlify
